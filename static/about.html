About dns-audit.com

What This Tool Does

dns-audit.com performs comprehensive DNS and email security audits against current RFC standards. It evaluates DMARC, SPF, DKIM, MTA-STS, TLS-RPT, DANE, DNSSEC, CAA, BIMI, and nameserver configuration, then reports findings and fixes against current RFC standards.

Unlike most DNS lookup tools that simply display records, dns-audit.com analyzes your configuration for dangerous tag combinations, validates against RFC specifications, detects your email service providers, and provides actionable recommendations with copy-paste DNS records.

DMARCbis Awareness

This tool validates against both RFC 7489 (current DMARC) and draft-ietf-dmarc-dmarcbis, the upcoming revision. It implements the DMARCbis DNS Tree Walk algorithm for organizational domain discovery, supports new tags (np=, psd=, t=), flags deprecated tags (pct, ri, rf), and generates migration paths to DMARCbis-ready records.

Methodology

All checks use live DNS queries against published records. No data is collected from email headers or message content. DKIM selector discovery tests over 1,100 common patterns using SPF-based sender detection.

Privacy

dns-audit.com queries only publicly available DNS records. No user accounts, no cookies, no tracking. IP addresses are held in memory for rate limiting and are not written to disk. Audit logs record audit metadata (domain, audit duration, browser identifier) only. Full details are in the Privacy Policy.

Open Source

The complete source code is available on GitHub under the MIT License. Security researchers can review the Security Policy for responsible disclosure guidelines.
