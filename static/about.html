About

I built dns-audit.com because the tools I wanted didn't exist.

Most DNS tools show you what records you have. They leave you to figure out whether those records are correct, whether the tag combination is dangerous, whether the RFC you're reading is the one that's actually current. I wanted something that did the analysis, showed the work, referenced the specific RFC section it was checking against, and gave me the exact records I needed to fix what was wrong.

So I built it.

It checks your DNS and email security configuration against current standards, flags misconfigurations, and gives you copy-paste fixes. DMARC validation runs against RFC 7489, the standard receivers use today. SPF, DKIM, DNSSEC, MTA-STS, TLS-RPT, DANE, CAA, BIMI, and nameserver configuration are all covered. The tool also looks ahead to DMARCbis and shows you what will need to change when the new spec lands.

If you manage DNS for a domain someone depends on, this tool was built for you.

It's free. No accounts, no cookies, no tracking. The code is open source under the MIT License. You can read it, run it locally, or fork it.

I'm Neil Anuskiewicz. I hope it catches an issue before it turns into an email deliverability headache.

Privacy

No accounts. No cookies. No tracking. Your IP address is held in memory for rate limiting and never written to disk. Audit logs record the domain, audit duration, and a truncated browser identifier. No IP addresses in the logs. DNS snapshots store public record data for change tracking and are deleted after 90 days.

All traffic passes through Cloudflare. No third-party scripts, fonts, or analytics.
