Privacy & Terms

Privacy

  • We don't collect personal data. No accounts, no cookies, no tracking.
  • When you run an audit, we query public DNS records for the domain you enter. That's it.
  • We don't store audit results permanently. Cached results expire within minutes.
  • We log basic request data (IP address, domain queried, timestamp) for rate limiting and abuse prevention. These logs are not shared with anyone.
  • We use Cloudflare as a CDN. Cloudflare has its own privacy policy.

Terms of Use

  • This tool queries public DNS records. It does not perform any intrusive security testing.
  • Results are informational only. We do our best to be accurate, but DNS can be complex and we can't guarantee every result is perfect.
  • Don't abuse the service (automated bulk queries, scraping, etc.). We rate-limit to keep things fair for everyone.
  • This is a free tool provided as-is. No warranties, no SLA.
