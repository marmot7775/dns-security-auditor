Privacy & Terms

Last updated: April 2026

What We Collect

When you run an audit, we process the following:

The domain you enter. We query public DNS records on your behalf. DNS records are public by design. This is not personal data.

Your IP address, temporarily. We hold it in memory for rate limiting. It is not written to disk, not logged, and is cleared when the server restarts.

An audit log entry. We record which domain was queried, how long the audit took, the resulting grade, and a truncated browser identifier (the first 50 characters of the User-Agent header). This helps us monitor service health. IP addresses are not included in the log.

DNS snapshots. We store snapshots of public DNS records to track changes over time. Snapshots are retained for 90 days, then automatically deleted. This is public data. No personal information is attached to snapshots.

If you provide a custom DKIM selector, we use it for that audit only.

Data Retention

Audit results are cached in server memory for 5 minutes to reduce redundant DNS queries, then discarded.

Audit log files rotate automatically and are managed by the operating system. They do not contain IP addresses.

Rate limit data is held in memory only and cleared on restart.

DNS snapshots are retained to enable change tracking. They contain only public DNS record data.

Third Parties

All traffic passes through Cloudflare, which provides CDN and DDoS protection. Cloudflare processes your IP address and request headers as part of its service. Their privacy policy is at cloudflare.com/privacypolicy.

dns-audit.com does not load fonts, scripts, analytics, or any other resources from third-party services. All assets are served from the same origin.

How Audits Work

When you run an audit, our server queries public DNS infrastructure: authoritative nameservers, public resolvers, Certificate Transparency logs, and DNS-based blocklists. All of this information is publicly available to anyone with a DNS client. The audit is read-only and non-intrusive.
